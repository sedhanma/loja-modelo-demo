# loja-modelo-demo

Demonstração online de um modelo de site para loja de celular, no GitHub Pages (branch `main`, raiz do repositório, em `/loja-modelo-demo/`). Aparelhos, contatos e textos são de exemplo — não há dados de nenhuma loja real.

O site fica em modo demonstração: o Firebase permanece como `TODO`, a vitrine mostra aparelhos de exemplo e o painel aceita o usuário `loja` com qualquer senha. Tudo fica só neste navegador. Os formulários não enviam e-mail; o envio apenas simula o sucesso na tela.
