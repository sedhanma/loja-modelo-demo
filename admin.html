Quase lá! Falta conectar o banco de dados

Este painel guarda os cadastros no Firebase (gratuito). Para ativar:

  1. Crie o projeto no Firebase e ative Firestore e login por e-mail/senha.
  2. Cole o firebaseConfig no arquivo js/config.js.
  3. Publique as regras do arquivo firestore.rules.

O passo a passo completo está no arquivo GUIA-INSTALACAO.md.
